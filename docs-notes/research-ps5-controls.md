# 調査メモ: PS5版の操作方法（2026-11-03）

ユーザーが実機(PS5)の画面をスクショで提示した内容をまとめたもの。**まだWikiには載せていない**。ユーザー方針は次のとおり。
- 載せるのはPS5版のみ。PC版・Xbox版は「情報を募集しています」と書く。
- 「実機確認」はスクショの画面表示。「申告」はユーザーの口頭の説明（画面に写っていない）。

## 2. 建設メニュー（R2の円形メニュー。実機確認）
- L1/R1でタブを左右に移動する（画面下に「L1」「R1」の表示、ユーザー申告で確認）。
- 画面右下に「R2 長押ししてメニューを切り替え」と出る。切り替え先は未確認。
- タブ（画面下の日本語表示）: 都市警備、祭壇、軍事施設、港湾施設、原料、インフラ、リベルトゥス、プレブス、エクィテス、パトリキ（計10）。
- 輪の中身はアイコンから概要を読んだだけ。個別の建物名は未確認。
- お気に入りに追加: 建物を選んで**三角長押し**（申告）。星のマークがお気に入りの印と思われる（推測）。

## 5. 解体モード（実機確認）
- ツールの説明は「破壊する: 建物、道路、オブジェクトを破壊する。」。カーソルはつるはし。
- メニュー内のR1で切り替え: 「選択したものをすべて解体」/「同一のインフラのみを解体」。丸で戻る。
- 解体・アップグレードではグリッドによる範囲選択ができる（申告）。
- **範囲選択の操作（申告）**: 決定ボタン（バツ）を長押ししながらスティックで範囲を選び、ボタンをはなして確定。解体で確認。アップグレードも同じ操作かは未確認。
- 範囲選択中の画面（実機確認）: 赤い四角の枠で囲んだ範囲の建物が赤く光る（解体の対象）。右側に「破壊する」「解体すると払い戻される」と、払い戻しの量（例: 木材+2）。建物の上に道路のアイコンが出る（赤=範囲内、白=範囲外。意味は画面に説明なし）。右端のサイドバーに解体アイコンと三角。画面下の操作ガイドは写っておらず未確認。
- 未確認: メニューを開くボタン、初期状態、「同一のインフラのみ」の実際の挙動、範囲を広げたときの払い戻しの合計表示、道路アイコンの意味。

## 5b. 道路を引く・アップグレード（画面は実機確認、操作はユーザー申告）
- **ドラッグ操作は共通（申告）**: 道路を引くときも、アップグレードの範囲選択も、解体と同じ。バツ（決定）を長押ししたままスティックで動かし、はなして確定する。道路は始点を決め、動かして、はなして確定する流れ。
- 道路（砂利道）を引いている画面: 右に「砂利道 / 道路 / 建物同士を結び、品物の輸送を可能にする。」、建設費33コイン（引いた長さの合計と思われる）。地面に土の道のプレビュー。右端のサイドバーに格子のアイコン（斜めの建設オフ時の表示と思われる）、別のアイコン、三角。
- アップグレードの画面: 対象の道路が緑に光り、上向き矢印のマーク。右のパネルに上向き矢印（選択中）と下向き矢印、その下に十字キーのアイコン。説明は「アップグレード / アップグレード費用: コイン1と、もう1つの資材1」。
- **十字キーで上向き（アップグレード）と下向き（ダウングレード）を切り替える（申告）**。画面には説明の文字はない。
- 未確認: アップグレードでもう1つの資材の名前、サイドバーの2つ目のアイコンの意味。

## 6. L2クイックメニュー（実機確認）
8枠。**装飾ツール以外の7枠は変更できる**（申告）。星のマークはお気に入りの印と思われる（推測）。

| 位置 | 初期表示 | 説明（画面の表示） |
|---|---|---|
| 上 | リベルトゥスの住居（ローマの住居） | あなたの住民はここに住む。住民の需要を満たすとアップグレードできるようになる。 |
| 右上 | 装飾ツール（変更不可） | 施設や船の見た目をカスタマイズする |
| 右 | アップグレード | 建物を次のレベルにアップグレードするか、計画済みの建物を完成させるか、廃墟を修理する。 |
| 右下 | 複製する | 1つ、または複数の建物をコピーして、望みの場所に配置する、（読点で終わるのは画面のまま） |
| 下 | 破壊する | 建物、道路、オブジェクトを破壊する。 |
| 左下 | 移転する | 建物を同じ島の新しい位置に移動できる。 |
| 左 | 道路（砂利道）（申告） | 画面に名前は出ていない。編集画面で「砂利道 道路 建物同士を結び…」と確認 |
| 左上 | 倉庫（インフラ施設） | 生産施設と品物をやり取りして流通させる。 |

ボタン:
| ボタン | 操作 |
|---|---|
| スティックを倒す | 枠を選ぶ（名前と説明が出る。倒さないと「丸 戻る」だけ） |
| 三角 | お気に入りを削除 |
| 四角 | 編集（「ショートカットを編集」画面が開く） |
| 丸 | 戻る |

- お気に入りは**7スロット。空きがないと追加できず、先に削除が必要**（申告）。
- 「ショートカットを編集」画面: タブは「建物」「ツール」（L1/R1で切り替え）、中身は格子状のアイコン。選んだものの説明と建設費が出る（例: 砂利道は10タイルあたり50コイン）。
- 未確認: 格子の中から選ぶ決定ボタン、すでに他の枠にあるものを選んだときの動作、L2メニュー上部のメモ追加風アイコンの意味。
