# DLC03「デルタの夜明け」・アップデート3.0 実機確認シート

作成: 2026-10-06（配信前）。配信予定日は 2026-11-05。

PS5の実機で何を控えれば、wikiと計算機に反映できるかをまとめた記入用のシートです。
公式データ（assets.xml）が今回は手に入らない見込みが高いため、実機の表示を一次情報として扱います。

## 使い方

- 欄は埋められるところからで構いません。分からない欄は空欄のままにします（推測で埋めない）。
- 文字で書き写す代わりに、スクリーンショットを撮って渡してもらえば、こちらで読み取ります。
- **数値は、信仰神・アイテム・スキル・隣接効果などのバフが乗っていない状態**で控えます。乗っている場合は、その旨をメモします。
- 名前は**日本語版の画面の表記をそのまま**書きます。配信前に載せた「スレッシャー」「スクライブ」「ポッター」などは仮の訳です。
- 実機と公式データが食い違ったら、実機を優先します（従来どおり）。

## 優先順位

1. 名前の確定（属州・住民層・商品・建物・祭神）… 配信前に載せた仮の訳を直すため、最優先
2. 住民層の需要と分岐 … 住民層ページの「準備中」を埋める
3. 生産建物（サイクルタイム・入力・出力）… 計算機と生産チェーン図に必要
4. 新祭神・灌漑・軍事ユニット・スキルツリー
5. 3.0で変わった既存の数値

### v2.1の公式データで「Egyptian」の印が付いている67件（配信前のデータ・要検証）

v2.1（DLC03配信前）の `assets.xml` の Product 資産155件のうち、地域の印に `Egyptian` を含むものです。
配信前に仕込まれたデータなので、3.0で変わっている可能性があります。**実機で確かめるまでwikiには載せません。**

印は2種類あります。

- `ProductionRegions`（生産地域）: その地域で**生産できる**ことを示すとみられる印。58件（商品51・公共サービス7）
- `AssociatedRegion`（関連地域）: その地域に**関係する**ことを示すとみられる印。生産地域の印が無く、こちらだけに `Egyptian` が付くものが9件。アイギュプトでは作れず、交易で持ち込んで使う商品の可能性があります

2つの印の意味は、既存2地域での付き方からの推定です（公式の説明はありません）。

## 配信後に決めること

- 計算機でアイギュプトを選んだときの切替ボタンの見た目（いまは文字だけ）
- 生産チェーンのファイル名の付け方（既存はアルビオン版が `<商品id>_albion.json`。`generate-goods-list.ts` は `_albion` を含むファイルをアルビオン扱いにするので、アイギュプト版は別の接尾辞にして `region` で指定する）
- 建設資材が増えた場合の `building_cost` の項目追加（計算機の表示にも影響）
- 維持費の労働力に新しい層が増えるため、計算機・建物効果の層の一覧への追加
