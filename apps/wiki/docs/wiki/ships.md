# 船データ

造船所で建てられる船と、海の船に付けるモジュールの数値の一覧です。数値はゲームのデータが元で、実機との照合は未確認です。

- **海の船**は、ラティウム・アルビオン・アイギュプトの造船所で、同じ3種（ペンテコンター・トライリーメ・クィンクェレメ）を建てられます。数値は3地域とも同じで、維持費の労働力の種類だけが違います（下の表）。
- 造船所の建造メニューには「民間」と「軍団」の編成が並びます。違いは船体ではなく、あらかじめ付いているモジュールの組み合わせです。
- **ナイルの川船**は、アイギュプトのナイルの造船所で建てます。モジュールの改造はできません。小型がエポルキオン、中型がアバです（名前と船の対応は、大きさから決めています。未確認です）。アバには、民間と軍用があります。
- 積載は、積める枠の数と、1枠に積める量の上限です。
- 速度と戦力点は、ゲームのデータの値です。単位や、ゲーム内のどこに出るかは確認していません。
- イベントやクエストの専用の船は載せていません。
