# 住民層

Anno 117 には<strong>ラティウム（ローマ）</strong>と<strong>アルビオン（ケルト）</strong>の2系統の住民層があります。DLC03「デルタの夜明け」（2026年11月5日追加）で、3系統目の<strong>アイギュプト（エジプト）</strong>が加わりました。

## 需要システムの仕組み

- **カテゴリ制:** 各層に食料・ファッション・家庭・公共などのカテゴリがあり、各カテゴリを100％以上にすることで上位層へ昇格できます
- **需要率:** 同一カテゴリ内の複数品目は「100～200％の範囲」。100％以上供給すると住民の収入等が増加します
- **上位互換消費:** 上位層の住民も下位層の需要を引き続き消費します

## アイギュプト住民層

> 数値は、ゲームのアップデート3.0のゲーム内データです。需要の数量と昇格条件は載せていません。実機の画面との照合は未確認です。上位の層は、下位の層の需要も引き続き消費します（下の表は、1つ下の層から増える需要です）。
>
> 出典: [Anno Union公式ブログ「Gamescom recap: Dawn of the Delta and Echoes of Kassandra」](https://www.anno-union.com/gamescom-recap-dawn-of-the-delta-and-echoes-of-kassandra/)（2026年9月3日）、[「Population, Floods and the power of knowledge」](https://www.anno-union.com/devblog-population-floods-and-the-power-of-knowledge/)（デブログ第2回、2026年10月22日）

アイギュプトでは、最初の層から<strong>ギリシャ・ローマ文化</strong>と<strong>クマト文化</strong>の2つの路線に分かれます。各路線は3段階で、最初の麦打ち人の上に、路線ごとの第2階層と第3階層が続きます。

![アイギュプト住民層の進化](/diagrams/aegyptus-tiers.svg)

### 麦打ち人

アイギュプトの最初の層です。この土地の農業の伝統を担います。

| カテゴリ | 商品・施設 |
|--------|-----------|
| 食料 | ナツメヤシ、お粥 |
| ファッション | ウェセクの首輪、チュニック |
| 公共サービス | 市場、焚き火 |

---

### 書記（ギリシャ・ローマ文化路線）

ギリシャ・ローマ文化と融合する路線です。麦打ち人の需要を満たすと上がれます。

**追加需要（書記固有）:**

| カテゴリ | 商品・施設 |
|--------|-----------|
| 食料 | パン、チーズ |
| ファッション | サンダル、石鹸、ブローチ |
| 家庭 | 書記道具一式、オリーブオイル |
| 公共サービス | ラテン語学校、聖域 |

学者や行政官の層で、ギリシャ文化の影響が強く、エジプト人をやや見下す傾向があります。書記道具一式は、パピルス（葦が必要）と、現地の鉱物から作る顔料で作ります。

---

### ギムナシアリコス（ギリシャ・ローマ文化路線の第3階層）

商業で富を得た、教養のある上流層です。

**追加需要（ギムナシアリコス固有）:**

| カテゴリ | 商品・施設 |
|--------|-----------|
| 食料 | 希少な肉の盛り合わせ、ワイン、鳥舌肉アスピック |
| ファッション | ネックレス、ポッパエアのミルク、かつら |
| 家庭 | 象牙の小箱、肘掛け椅子 |
| 公共サービス | 貯水池、劇場、賭博場 |
| 驚異 | 浴場、図書館、改修されたピラミッド |

威信と収入が大きく増えます。ローマ式の公共施設（劇場・浴場・図書館）が使えます。浴場には水道橋が必要で、水道橋は灌漑にも使います。

---

### 陶工（クマト文化路線）

クマトの伝統を守る路線で、革新には消極的です。麦打ち人の需要を満たすと上がれます。

**追加需要（陶工固有）:**

| カテゴリ | 商品・施設 |
|--------|-----------|
| 食料 | 詰め物入りガチョウ、ビール |
| ファッション | シェンティ、コール |
| 家庭 | 魔除けのお守り、オイルランプ、角杯、小像 |
| 公共サービス | 薬屋、聖域 |

魔除けのお守りは、銅と砂から作った青い染料で、現地の粘土を染めて作ります。

---

### 奉唱巫女（クマト文化路線の第3階層）

陶工を満足させると解放される、女司祭の層です。

**追加需要（奉唱巫女固有）:**

| カテゴリ | 商品・施設 |
|--------|-----------|
| 食料 | カフク、青スイレン茶 |
| ファッション | カラシリス、香油、外套 |
| 家庭 | シストラム、高級ガラス、手鏡 |
| 公共サービス | 岩窟墓、劇場、賭博場 |
| 驚異 | 神殿、天文台、改修されたピラミッド |

どれも高価ですが、満足度と威信が大きく上がります。シストラムは、現地の銅と錫から作った青銅に、氾濫原のビーズを組み合わせて作ります。

---

### 路線ごとの公共施設

| 路線 | 施設 |
|--------|-----------|
| クマト文化 | 薬局（薬草園つき。健康と知識）、聖域または神殿（現地の神々）、岩窟墓（上流階級向け。山のスロットが必要）、天文台（信仰+5、知識+3） |
| ギリシャ・ローマ文化 | 劇場、浴場（水道橋が必要）、図書館（オイルランプに注意） |
