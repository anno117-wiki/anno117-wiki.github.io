# 住民層

Anno 117 には<strong>ラティウム（ローマ）</strong>と<strong>アルビオン（ケルト）</strong>の2系統の住民層があります。DLC03「デルタの夜明け」（2026年11月5日追加）で、3系統目の<strong>アイギュプト（エジプト）</strong>が加わりました。

## 需要システムの仕組み

- **カテゴリ制:** 各層に食料・ファッション・家庭・公共などのカテゴリがあり、各カテゴリを100%以上にすることで上位層へ昇格できます
- **需要率:** 同一カテゴリ内の複数品目は「100〜200%の範囲」。100%以上供給すると住民の収入等が増加します
- **上位互換消費:** 上位層の住民も下位層の需要を引き続き消費します

## ラティウム住民層

![ラティウム住民層の進化](/diagrams/latium-tiers.svg)

### リベルトゥス

ラティウムの最下層住民です。ゲーム開始時から存在する基本労働力です。

| カテゴリ | 商品・施設 |
|--------|-----------|
| 食料 | イワシ（必須）、お粥、パン（輝きで追加）、ビール（研究で追加） |
| ファッション | チュニック、ピレウス帽 |
| 公共サービス | 市場、酒場 |

- <strong>パン</strong>：円形闘技場の輝きがランクIVになると加わる需要です（アップデート2.0から）。気づかないうちにパンの消費が増えるので注意。この消費量は、アップデート3.0でプレブスと同じ水準まで下がりました。詳しくは[モニュメントの輝き](/wiki/splendor)にあります。
- <strong>ビール</strong>：社会のスキル「ケレースとバッカス」を研究すると加わる需要です。満たすと人口+1・収入+1・幸福+2、知識は-1です。スキルは[スキルツリー・社会](/wiki/techs-civic)にあります。

### エクィテス

プレブスの需要を充足後にアップグレードできます。

**追加需要（エクィテス固有）:**

| カテゴリ | 商品・施設 |
|--------|-----------|
| 食料 | ワイン、チーズ |
| ファッション | トガ、ブローチ |
| 家庭 | 筆記板、高級ガラス、馬（輝きで追加）、小像（研究で追加） |
| 公共サービス | 貯水池、劇場、賭博場（研究で追加） |
| 驚異 | 公共広場、浴場 |

- <strong>馬</strong>：競馬場の輝きがランクVIIになると加わる需要です。エクィテスが800人以上いると求められます。パトリキにも引き継がれます。詳しくは[モニュメントの輝き](/wiki/splendor)にあります。
- <strong>小像</strong>：DLC01のスキル「黒曜石の小像」を研究すると加わる需要です。スキルは[スキルツリー・灰の予言](/wiki/techs-dlc01)にあります。
- <strong>賭博場</strong>：社会のスキル「イチかバチか」を研究すると加わる需要です。スキルは[スキルツリー・社会](/wiki/techs-civic)にあります。

<strong>アップデート3.0で追加された需要:</strong> アイギュプトの商品が加わりました。食料の<strong>ナツメヤシ</strong>、ファッションの<strong>コール</strong>、家庭の<strong>書記道具一式</strong>です。ナツメヤシの画面には「必要な品物が生産できる場所: アイギュプト」と出ます。ラティウムの島で満たすには、アイギュプトで作った商品を運んでくる必要があります。

エクィテスの需要を充足後にアップグレードできます。最高税収・名声を誇る最上位層です。

**追加需要（パトリキ固有）:**

| カテゴリ | 商品・施設 |
|--------|-----------|
| 食料 | 牡蠣のキャビア添え、鳥舌肉アスピック |
| ファッション | ネックレス、外套 |
| 家庭 | 肘掛け椅子、手鏡 |
| 公共サービス | 神殿、図書館 |
| 文化 | 竪琴、戦車、ラトルンクリ一式（研究で追加） |
| 驚異 | 円形闘技場、競馬場 |

- <strong>ラトルンクリ一式</strong>：DLC01のスキル「ラトルンクリ」を研究すると加わる需要です。スキルは[スキルツリー・灰の予言](/wiki/techs-dlc01)にあります。

<strong>アップデート3.0で追加された需要:</strong> エクィテスと同じアイギュプトの3商品（ナツメヤシ・コール・書記道具一式）に加えて、食料の<strong>カフク</strong>、ファッションの<strong>ポッパエアのミルク</strong>、家庭の<strong>象牙の小箱</strong>、文化の<strong>シストラム</strong>が加わりました。どれもアイギュプトの商品です。

## アルビオン住民層

アルビオンでは ティア2以降に**ケルト文化**と**ローマ文化**の2つの路線があります。先に進めた路線の第3層が1人以上いると、もう一方の路線にも上がれます（ケルト文化を先に進めたときはアルダー、ローマ文化を先に進めたときはノビレスが1人以上）。

![アルビオン住民層の進化](/diagrams/albion-tiers.svg)

### ウェーダー

アルビオンの共通基本層です。文化選択前の住民です。

| カテゴリ | 商品・施設 |
|--------|-----------|
| 食料 | ザル貝（必須）、ウナギ（必須）、ガルム（研究で追加） |
| ファッション | チュニック、葦の靴 |
| 公共サービス | 市場、吟遊詩人の暖炉 |

- <strong>ガルム</strong>：社会のスキル「味付け」を研究すると加わる需要です。スキルは[スキルツリー・社会](/wiki/techs-civic)にあります。

## アイギュプト住民層

> 需要の数量は載せていません。昇格の条件は、各カテゴリの需要を100%以上満たすことです。ただし、陶工の路線を先に進めている場合、書記には奉唱巫女が1人以上いることも条件です。書記の路線を先に進めている場合は、陶工にギムナシアリコスが1人以上いることが条件です。ギムナシアリコスと奉唱巫女への昇格は、それぞれ書記・陶工の需要を100%以上満たせばできます。上位の層は、下位の層の需要も引き続き消費します（下の表は、1つ下の層から増える需要です）。

アイギュプトでは、最初の層から<strong>ギリシャ・ローマ文化</strong>と<strong>クマト（伝統）</strong>の2つの路線に分かれます。各路線は3段階で、最初の麦打ち人の上に、路線ごとの第2層と第3層が続きます。

![アイギュプト住民層の進化](/diagrams/aegyptus-tiers.svg)

### 麦打ち人

アイギュプトの最初の層です。この土地の農業の伝統を担います。

| カテゴリ | 商品・施設 |
|--------|-----------|
| 食料 | ナツメヤシ、お粥 |
| ファッション | ウェセクの首輪、チュニック |
| 公共サービス | 市場、焚き火 |

---

### 書記（ギリシャ・ローマ文化路線）

ギリシャ・ローマ文化と融合する路線です。麦打ち人の需要を満たすと上がれます（陶工の路線を先に進めている場合は、奉唱巫女が1人以上いることも条件です）。

**追加需要（書記固有）:**

| カテゴリ | 商品・施設 |
|--------|-----------|
| 食料 | パン、チーズ |
| ファッション | サンダル、石鹸、ブローチ |
| 家庭 | 書記道具一式、オリーブオイル |
| 公共サービス | ラテン語学校、聖域 |

学者や行政官の層で、ギリシャ文化の影響が強く、エジプト人をやや見下す傾向があります。書記道具一式は、パピルス（葦が必要）と、現地の鉱物から作る顔料で作ります。

---

### ギムナシアリコス（ギリシャ・ローマ文化路線の第3層）

商業で富を得た、教養のある上流層です。

**追加需要（ギムナシアリコス固有）:**

| カテゴリ | 商品・施設 |
|--------|-----------|
| 食料 | 希少な肉の盛り合わせ、ワイン、鳥舌肉アスピック |
| ファッション | ネックレス、ポッパエアのミルク、かつら |
| 家庭 | 象牙の小箱、肘掛け椅子 |
| 公共サービス | 貯水池、劇場、賭博場（研究で追加） |
| 驚異 | 浴場、図書館、改修されたピラミッド |

- <strong>賭博場</strong>：社会のスキル「イチかバチか」を研究すると加わる需要です。スキルは[スキルツリー・社会](/wiki/techs-civic)にあります。

名声と収入が大きく増えます。ローマ式の驚異（浴場・図書館）が使えます。浴場には水道橋が必要で、水道橋は灌漑にも使います。

---

### 陶工（クマト（伝統）路線）

クマトの伝統を守る路線で、革新には消極的です。麦打ち人の需要を満たすと上がれます（書記の路線を先に進めている場合は、ギムナシアリコスが1人以上いることも条件です）。

**追加需要（陶工固有）:**

| カテゴリ | 商品・施設 |
|--------|-----------|
| 食料 | 詰め物入りガチョウ、ビール |
| ファッション | シェンティ、コール |
| 家庭 | 魔除けのお守り、オイルランプ、角杯、小像（研究で追加） |
| 公共サービス | 薬屋、聖域 |

- <strong>小像</strong>：DLC01のスキル「輸入神」を研究すると加わる需要です。スキルは[スキルツリー・灰の予言](/wiki/techs-dlc01)にあります。

魔除けのお守りは、銅と砂から作った青い染料で、現地の粘土を染めて作ります。

---

### 奉唱巫女（クマト（伝統）路線の第3層）

陶工を満足させると解放される、女司祭の層です。

**追加需要（奉唱巫女固有）:**

| カテゴリ | 商品・施設 |
|--------|-----------|
| 食料 | カフク、青スイレン茶 |
| ファッション | カラシリス、香油、外套 |
| 家庭 | シストラム、高級ガラス、手鏡 |
| 公共サービス | 岩窟墓、劇場、賭博場（研究で追加） |
| 驚異 | 神殿、天文台、改修されたピラミッド |

- <strong>賭博場</strong>：社会のスキル「イチかバチか」を研究すると加わる需要です。スキルは[スキルツリー・社会](/wiki/techs-civic)にあります。

「改修されたピラミッド」は、州全体のプロジェクトで修復したピラミッドが満たす需要です。ゲーム内のヘルプ（ピラミッドの改修）では、修復されたピラミッドは、誰が修復を完了したかに関わらず、アイギュプトのすべての奉唱巫女とギムナシアリコスの公共サービス需要を満たす、と説明されています。自分で建てる建物ではありません。

どれも高価ですが、幸福度と名声が大きく上がります。シストラムは、現地の銅と錫から作った青銅に、氾濫原のビーズを組み合わせて作ります。

---

### 路線ごとの公共施設

| 路線 | 施設 |
|--------|-----------|
| 両路線に共通 | 聖域（第2層から）、劇場・賭博場（第3層から） |
| クマト（伝統） | 薬屋（陶工。薬草園つき。健康と知識）、岩窟墓（奉唱巫女。山のスロットが必要）。驚異は神殿・天文台（信仰+5、知識+3） |
| ギリシャ・ローマ文化 | ラテン語学校（書記）。驚異は浴場（水道橋が必要）・図書館（オイルランプに注意） |
