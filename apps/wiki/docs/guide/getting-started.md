# はじめに

Anno 117 統合Wiki へようこそ。Anno 117（PS5 / Steam）の日本語情報Wikiと生産チェーン計算機を1つにまとめたサイトです。

## 構成

本サイトは大きく二つに分かれています。

- **Wiki（本サイト）** — 商品・生産・地域などの情報を日本語でまとめた解説ページ
- **計算機** — 生産チェーンを展開して、必要な建物数・原料を計算する専用ツール

## 計算機を使う

生産チェーンを計算したいときは、ナビゲーションの「計算機」か、トップページの「計算機を開く」から計算機ページに移動してください。

計算機では商品をツリーから選ぶだけで、生産チェーンと必要量が確認できます。

## データの出典

商品・生産チェーンのデータは、anno-calculator公式（GitHub: agentquackyt/Anno117Calculator）のものを使っています。
