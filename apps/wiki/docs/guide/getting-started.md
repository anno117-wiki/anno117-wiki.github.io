# このサイトについて

Anno 117（PS5 / Steam）の日本語情報Wikiと、生産チェーン計算機のサイトです。

## 計算機

商品をツリーから選ぶだけで、生産チェーンと必要な建物数・原料が分かります。
使い方は[計算機の使い方](/guide/calculator-guide)にあります。

## データについて

商品・生産チェーンのデータは、anno-calculator公式（GitHub: agentquackyt/Anno117Calculator）を元にしています。

ゲームの数値は、ゲーム内データと、PS5の実機での確認が元です。DLC03（アイギュプト）と無料アップデート3.0の分は、ゲーム内データ（アップデート3.0）から作っていて、実機との照合が済んでいないものがあります。そうした数値には「未確認です」と書いています。実機と食い違っていたときは、実機の値を優先して直します。
