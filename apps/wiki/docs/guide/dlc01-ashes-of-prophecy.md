# DLC01・灰の予言

## 概要

- Anno 117内で **最大級の火山島**が登場し、定期的に噴火を起こします。
- 噴火によりラティウム全域に地震が発生し、建物に被害が出ます。
- 火山島内にカエシリアの港が追加され、新アイテムが黒曜石と交換で入手できます。
- 火山ならではのイベントが多数追加されています。
- 新祭神「ウルカヌス」が追加されました。信仰4,000で**炭鉱**が解放されます。（[詳細](/wiki/patrons#vulcan)）

## 解放要素

- 商品追加：[ラトルンクリ一式](/wiki/production-chains#latrunculi_sets)・[小像](/wiki/production-chains#statuettes)。
- 新素材 **黒曜石**：鉱山（スキル解放要）や採石場などからの副産物として生成されます。
- 黒曜石は島ごとに埋蔵量が設定されており、掘り続けると枯渇します。
- 新スキルツリー「灰の予言」が解放されます。

## 初期クエスト

1. カエシリアから貢ぎ物イベントが発生します。
2. 黒曜石を要求されます。

## 火山イベント

1. 定期的に地震が起こるようになり、建物が破壊されます。（範囲はラティウム全土、島はランダム）
2. 噴火するか沈静化するかはランダムです。沈静化したら1に戻ります。
3. 噴火すると島全土に火山弾が降ってきて建物に被害が出ます。（噴火が続く時間は、ゲームのデータでは8分に、最大2分が加わります。実機では未確認です）
4. 軍事ユニットで住民の救出作業を行えば、1件当たり噴火時間が1分短縮されます。（移動速度の速い**騎兵**が活躍）
5. 噴火により火山弾が各地に落ちますが、回収すると**黒曜石**が入手できます。（海中のものは船で回収が必要）
6. 噴火が落ち着くと、今度は噴煙により農作物・海産物の生産性が <strong>-75%</strong> になります。（噴煙が続く時間は、ゲームのデータでは50分に、最大10分が加わります。実機では未確認です）
7. 食料の生産性が大きく低下するため、在庫ストックは多めに確保しておきましょう。
8. 噴煙が晴れると土地の肥沃度が上昇し（噴火のたびに+10%）、農産物の生産性が+10%、火山性土LVが+1されます。
9. 火山性土LVの上限はスキルにより解放されます。（初期値：3　最大値：5　肥沃度最大：<strong>+50%</strong>）
10. 以降、1に戻ります。

2026年5月1日追加。

### 噴火のサイクル

火山は「休火山 → 目覚め → 噴火 → 火山の冬 → 春の訪れ」の順にめぐって、また休火山に戻ります。各段階が続く時間は、ゲームのデータでは次のとおりです。実機では未確認です。

| 段階 | 続く時間 |
|---|---|
| 休火山 | 7時間35分＋最大1時間40分（最初の1回だけ1時間30分〜2時間15分） |
| 目覚め | 20分＋最大10分 |
| 噴火 | 8分＋最大2分 |
| 火山の冬 | 50分＋最大10分 |
| 春の訪れ | 1時間＋15〜30分（目覚め・噴火・火山の冬で足された時間も、ここに加わる） |

- 1周は最短で10時間8分、最長で12時間47分、平均だと約11時間半です（目覚めのあと沈静化せずに噴火まで進んだ場合）。
- 目覚めのあと沈静化すると、噴火せずに休火山へ戻ります。
