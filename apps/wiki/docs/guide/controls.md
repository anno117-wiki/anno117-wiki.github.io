# 操作方法（PS5版）

> PS5の実機の画面表示をもとにまとめています。ゲームの更新で変わることがあります。
> PC版・Xbox版の情報を募集しています。

小ネタ: [一人称モード（自由散策モード）](#first-person)

---

## 通常の画面

| ボタン | 操作 |
|---|---|
| L2 | クイックメニューを開く |
| R2 | 円形メニュー（建設メニュー）を開く |
| L1 | ユニットの複数選択 |
| R1 | カメラの速度・傾き |
| 左スティック | カメラの移動 |
| 右スティック | カメラの回転・ズーム |
| R3 | カメラのリセット |
| L3 | 島の選択、または次の島へ進む |
| <span class="pad pad-tri" role="img" aria-label="三角ボタン"></span> | 要請を選択する |
| <span class="pad pad-square" role="img" aria-label="四角ボタン"></span> | 船の移動 |
| <span class="pad pad-circle" role="img" aria-label="丸ボタン"></span> | 選択の取り消し |
| <span class="pad pad-cross" role="img" aria-label="バツボタン"></span> | 対象の選択 |

画面の端にあるメニューは、十字キーでフォーカスを移せます（上: トップバー、左: サイドバー、右: メニュー、下: ミニマップ）。

## 建物を建てる

R2で円形メニューを開き、L1 / R1でタブを切り替えて建物を選びます。

### 配置中の操作

| ボタン | 操作 |
|---|---|
| <span class="pad pad-cross" role="img" aria-label="バツボタン"></span> | 設置 |
| <span class="pad pad-square" role="img" aria-label="四角ボタン"></span> | 回転（時計回りのみ。行き過ぎたら回し直し） |
| L1 | 破壊する |
| <span class="pad pad-circle" role="img" aria-label="丸ボタン"></span> | キャンセル |
| <span class="pad pad-tri" role="img" aria-label="三角ボタン"></span> | 建設モードのメニューを開く |

### 建設モードのメニュー

| ボタン | 操作 |
|---|---|
| <span class="pad pad-tri" role="img" aria-label="三角ボタン"></span> | 通常モードと計画モードの切り替え |
| <span class="pad pad-square" role="img" aria-label="四角ボタン"></span> | 斜めの建設のオン・オフ |
| <span class="pad pad-circle" role="img" aria-label="丸ボタン"></span> | 戻る |

同じ<span class="pad pad-square" role="img" aria-label="四角ボタン"></span>でも、配置中は「回転」、メニューの中は「斜めの建設」になります。

## 解体・アップグレード・道路

範囲を選ぶ操作は共通です。

1. <span class="pad pad-cross" role="img" aria-label="バツボタン"></span>を長押しする
2. 押したまま左スティックで範囲を動かす
3. ボタンをはなして確定

- **解体**: メニュー内のR1で「選択したものをすべて解体」と「同一のインフラのみを解体」を切り替えます。解体すると資材が払い戻されます。
- **アップグレード**: 十字キーの上下で、アップグレードとダウングレードを切り替えます。廃墟の修復もこのツールでできます。L1で「すべての廃墟」と「同じ種類の廃墟だけ」を切り替えます。
- **道路**: 始点を決め、動かして、はなして確定します。

## L2クイックメニュー

よく使うツールを8枠に登録できます。装飾ツール以外の7枠は入れ替えられます。

| 位置 | 初期の内容 |
|---|---|
| 上 | 住居 |
| 右上 | 装飾ツール（変更不可） |
| 右 | アップグレード |
| 右下 | 複製する |
| 下 | 破壊する |
| 左下 | 移転する |
| 左 | 道路 |
| 左上 | 倉庫 |

| ボタン | 操作 |
|---|---|
| スティック | 枠を選ぶ |
| <span class="pad pad-square" role="img" aria-label="四角ボタン"></span> | 編集 |
| <span class="pad pad-tri" role="img" aria-label="三角ボタン"></span> | お気に入りを削除 |
| <span class="pad pad-circle" role="img" aria-label="丸ボタン"></span> | 戻る |

## 船の選択

- L1を押しながら<span class="pad pad-cross" role="img" aria-label="バツボタン"></span>で、船を複数選べます。
- 船にカーソルを合わせて<span class="pad pad-cross" role="img" aria-label="バツボタン"></span>を2回押すと、画面上の同じ種類の船がすべて選ばれます。
- L1を押しながら<span class="pad pad-cross" role="img" aria-label="バツボタン"></span>を2回押すと、画面上の船がすべて選ばれます。

## 一人称モード（自由散策モード） {#first-person}

解放コマンドを入力すると使えます。建物も画面も選んでいない状態で、十字キーを **上・上・下・下・左・右・左・右** と押し、続けて **<span class="pad pad-circle" role="img" aria-label="丸ボタン"></span>・<span class="pad pad-cross" role="img" aria-label="バツボタン"></span>** を押します。

ゲームスピードを停止にした状態で入ると、自分視点（一人称）になります。停止以外で入ると、自分のキャラも見える三人称になります。

| 操作 | ボタン |
|---|---|
| 抜ける | <span class="pad pad-circle" role="img" aria-label="丸ボタン"></span>を長押し |
| ジャンプ（長押しで高く） | <span class="pad pad-cross" role="img" aria-label="バツボタン"></span> |
| ダッシュ | R2を長押し |
| キャラ切り替え | L1（人物は4キャラ。動物・背景物のときも、押すたびに順に変わる） |
| 固有アクション | <span class="pad pad-square" role="img" aria-label="四角ボタン"></span> |
| 姿の種類を変える | L2（人物、動物、背景物の順にループ） |
| 方角を表示 | Dパッド（どの方向でもよい。方角を示すパネルが出る） |

L2を押す前は人物です。L2を押すと、動物、背景物、人物の順に切り替わり、ループします。変身先は次のとおりです。

- 人物: 4キャラ
- 動物: 4種類（猫2種類、犬、キツネ）
- 背景物: 3種類（街路樹、低木、木箱）
