# 計算機の使い方

Anno 117 生産チェーン計算機の基本的な操作方法を説明します。

## 基本的な流れ

### 1. 商品を選ぶ

画面左のパネルにカテゴリ別の商品ツリーが表示されています。目的の商品をクリックすると、その商品の生産チェーンが中央パネルに表示されます。

### 2. 生産チェーンを確認する

中央パネルには、選択した商品を生産するために必要な建物と依存関係がグラフで表示されます。各ノードには建物名・必要件数が表示されます。

グラフの操作：

- **移動**（デスクトップ）: 左クリックしたままドラッグ
- **移動**（タッチ）: 1本指でドラッグ
- **拡大縮小**（デスクトップ）: マウスホイール
- **拡大縮小**（タッチ）: 2本指でピンチ

### 3. 数量を調整する

画面右のパネルで生産量の倍率を調整できます。目標とする生産数に合わせて必要な建物数が再計算されます。

### 4. 生産性の補正を入れる

画面右の「補正の設定」パネル（スマホは下の「補正」ボタン）で、生産性が上がる補正を選べます。選ぶとすぐ、必要な建物の軒数が再計算されます。

- **水道橋**: 「水路灌漑（農場）」「森の飲み水（農園）」「水力採鉱法（鉱山）」の3つです。研究ごとに、1つずつ選べます。どれも生産性が +50% です。
- **アイテム**: 選んでいる商品に効く専門家のアイテムが並びます。選んだアイテムの分だけ、生産性が足されます。並ぶのは生産性が上がるアイテムだけで、維持費や労働力が減るアイテムなどは入っていません。

### 5. ノードごとの補正

グラフのノードをクリックする（スマホはタップする）と、ポップアップが開きます。生産性・必要な建物数・建設費・維持費のほかに、「補正」の欄があります。

- **穀物庫**: アイギュプトの農場など、穀物庫の範囲効果を受ける建物のノードにだけ出ます。「なし」「穀物庫（+15%）」「大型穀物庫（+25%）」「広大な穀物庫（+35%）」から選びます。穀物庫の効果は範囲内の建物にだけ掛かるので、その農場が範囲内にあるかどうかは、自分で選んでください。大型と広大の値はゲームデータのもので、実機での確認は未確認です。
- **生産性を足す（%）**: どのノードにも出ます。一覧にない補正や、ゲーム内で見た値を、そのまま足し算で入れられます（-100〜1000）。Enter を押すか、入力欄から離れると反映されます。

補正が効いているノードは、角にアイコン（水道橋・穀物庫・アイテム）が重なります。2個まで並び、それより多いときは「+2」のように残りの数が出ます。木炭などの燃料を使う施設は、木炭が右下、補正が左下に出ます。

## その他の機能

### 地域切り替え

ヘッダーの地域ボタンから **ラティウム / アルビオン / アイギュプト（Aegyptus）** を切り替えられます（ボタンを押すたびに順番に切り替わります）。各地域固有の商品や建物が反映されます。

### アイギュプトを選んだとき

- アイギュプトだけの商品のうち、生産チェーンのある18点を計算できます。数値はアップデート3.0のゲーム内データです。
- 石炭や金鉱石は、作れる建物が2種類あります。そのため、コールと象牙の小箱は「コール（炭焼き師）」「コール（炭鉱）」「象牙の小箱（金選鉱）」「象牙の小箱（金鉱）」のように、建物ごとに別のチェーンになっています。図の素材名にも「金鉱石（金選鉱）」のように建物名が付くので、どちらの建物で作る場合かを見分けられます。
- ラティウム・アルビオンと共通の商品のうち、装甲・パン・チーズ・モザイク・サンダル・石鹸・瓦は、アイギュプトの建物で作るチェーンで計算できます。それ以外の共通の商品は、まだ対応していません。

### 言語切り替え

ヘッダーの「EN / 日本語」ボタンで表示言語を切り替えられます。

### 建設コスト・維持費

画面下部に、選択中の生産チェーン全体の建設コストと維持費の合計が表示されます。

## Wikiへ戻る

ヘッダー右上の「Wiki」リンクから Wiki トップへ戻ることができます。また、Wiki の商品一覧・生産チェーン一覧ページにある「開く」ボタンから、対応する商品を選択した状態で計算機を開けます。
