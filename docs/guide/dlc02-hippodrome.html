DLC02・競馬場 ​

出典: Anno Union 公式デブログ・Ubisoft News・実機確認。一部の数値は要検証。

概要 ​

  • ローマの戦車競走（チャリオットレース）をテーマにした2つ目のDLC。
  • 巨大モニュメント「競馬場」を段階建設し、住民向けのレースイベントを開催できる。
  • レースには手持ちの専門家（スペシャリスト）を騎手として出走させる。走らせるほど騎手の能力が育つ。
  • レースで貯まる輝きでモニュメントのレベルと島全体へのボーナスが強化される。
  • 同時配信の無料アップデート2.0で、名誉ある来賓・英雄級スペシャリスト・フォトモード等が全プレイヤーに追加。

競馬場モニュメント ​

  • 設置面積: 敷地は約60×28タイルで、円形闘技場（約28×28タイル）の約2倍の広さを要する。
  • 建設段階: 基礎 → 外壁・観客席 → 装飾・VIP用貴賓席の順に段階施工する（各フェーズの必要材料は下記「競馬場の建築工程」を参照）。
  • 需要充足: パトリキの「驚異」需要カテゴリーに属し、島全体のパトリキの当該需要を満たす。
  • 観客はエクィテス・パトリキ（貴賓席）から平民（一般席）まで全階層が楽しむ。

競馬場の建築工程 ​

  1. 新スキルツリー「競馬場」が追加される。まず競馬場スキルを解放する。
  2. 競馬場を設置する。円形闘技場と同様、資材搬入のため倉庫を近隣に置くことを推奨。
  3. 建設フェーズを順に進める。フェーズごとに必要材料と必要労働力が異なる。
フェーズ必要材料必要労働力
1設置のみ—
2木材 180／縄 150／瓦 150／布 120リベルトゥス 600人

  • 花崗岩・青銅などのアルビオン（ケルト）産の製品が必要になるため、事前に調達しておくとよい。

チャリオットレース ​

  • 出走させる騎手（スペシャリスト）は次の4能力を持つ。
    • 速度
    • スタミナ
    • ダッシュ
    • 信頼性
  • レース中はダッシュを発動して一時的に加速できる。
  • レース種別は3種。輝きレベルを上げると上位種別が解放される。
種別出走数解放条件
アマチュア4初期から
クラシック・クアドリガ6輝きレベルの上昇
インペリアル8輝きレベルの上昇
  • 大きなレースほど得られる輝きは多いが、必要な準備物資・対戦相手の強さも増す。
  • 騎手の育成: 出走を重ねると能力が伸びる。ただし騎手ごとに上限値と得意分野が異なる。

レースの流れ ​

  • レースは準備フェーズ → 試合フェーズ → クールダウン時間の順で進行する。
  • 試合フェーズが終了した時点で試走回数がリセットされる（最大回数は1回。スキル「たゆまぬ訓練」の解放で+2され、最大3回になる）。
  • 試走を行うと、ステータス上限に達していない場合はステータスが向上する。
  • ダッシュゲージが一定量まで上昇した時点でボタンを押すと、ダッシュが可能になる。

輝きボーナス ​

  • 獲得量はレース種別・供給した準備物資・着順で決まる。
  • 貯めた輝きでモニュメントのレベルと新レース種別が解放される。
  • レベルが上がると島全体に次の効果が生じる:
    • 周辺の生産力が上昇する。
    • 騎兵の攻撃・防御が強化される（+1 攻撃 / +2 防御）。
    • 上流階級（エクィテス／パトリキ）の需要に馬が追加され、馬ブリーダーが副産物として戦車を産出するようになる。

新規リサーチ・アイテム ​

  • 騎手育成に関わる新しいリサーチ技術が追加。
  • 関連アイテムはクエスト報酬・ウァレリアとの交易・反復リサーチで入手できる。

無料アップデート2.0（DLC不要） ​

  • 名誉ある来賓: 各地から来賓が訪れ、新スペシャリストなどをもたらす。出現率は名声（Prestige）と輝きのレベルに依存。
  • 英雄級（Heroic）スペシャリスト: 新レア度。極めて希少で名声コストが高く、セーブデータごとに各1体のみ所持可。効果は強力。
    • （例）「パルディウス」— チーズによる人口+2・健康+1、羊牧場のチーズ産出+1t/12サイクル、羊牧場の必要労働力を軽減。
  • フォトモード: フリーカメラ・時間帯選択・レンズ効果。
  • メモ機能: ゲーム内メモ。
  • 円形闘技場の9段階バフシステム。輝きレベルIVでリベルトゥスの需要にパンが追加される（気づかないうちにパン需要が急増するため要注意）。
  • 住民の反復クエスト。
  • パンの消費量+50%。供給時の人口ボーナスが+2→+3に増加し、小麦粉の生産時間が30秒/tから20秒/tに短縮。
  • 火災・疫病の建物への影響を強化。
