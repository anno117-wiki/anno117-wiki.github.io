アップデート・パッチ情報 ​

無料アップデートの変更点を、新しい順にまとめています。公式パッチノート（英語）から、遊びに関わるものと、PS5・PC版の主な修正を抜き出しました。細かい不具合の修正は省いています。全文は各版の公式ページで読めます。

版配信日同じ日に出たDLC

2.02026年8月20日DLC02・競馬場

3.0（2026年11月5日） ​

DLCを持っていなくても入る無料アップデートです。

新機能 ​

  • スタンプ機能：住居や生産施設の配置を保存して、あとで再利用できます。名前を付けたり、フォルダに分けたりもできます。PC版では、スタンプのファイルをほかの人と共有できます
  • 統計メニューに「保管」タブと「アイテム・スペシャリスト」タブを追加
    • 保管タブでは、保管中の商品、パッシブ貿易、アクティブ貿易、保管量の増減を確認できます
    • アイテム・スペシャリストタブでは、持っているスペシャリストと、まだ手に入れていないスペシャリスト、その入手元を一覧できます
  • クエストログからクエストを隠せるようになりました。隠したクエストは、クエストブックから戻せます
  • 前からのセーブを続ける人向けに、スタンプとメモ機能の短い紹介が出ます
  • 栄誉の殿堂に新カテゴリ「アイギュプト」が加わりました。DLC03を持っていなくても使えます

遊びやすさ ​

  • 祭りを自動で承認するオプションを追加（ゲームオプション）
  • 祭りの総督の決定で、費用の商品を今どれだけ持っているかが表示されます
  • アップグレードの道具で、費用と一緒に建物の名前が出ます
  • 交易ルートを消す前に確認が出ます
  • 交易ルートの詳細画面で戻る操作をすると、画面ごと閉じずにルートの一覧に戻ります
  • アイテムの持ち物を開くと、場面に合った絞り込みが最初から選ばれています
  • カーソルの下にある建物と同じものを建てるショートカットを追加（キーは自分で割り当てます）
  • フォトモードで、カメラを建物の中に入れられます

バランス調整 ​

  • 難易度：新しいセーブでは「ノーマル」が既定になり、商品の消費量が増えます。「簡単」も選べます。消費がさらに75%増える最上位の難易度も追加されました。開始資金も増えます。前からのセーブには影響しません
  • 祭り：始めるのに必要な商品が、商品の価値で決まるようになりました。安い商品は多く、高い商品は少なく必要です。終盤の祭りの費用は、50,000コインから25,000コインに下がります
  • 水道橋のスペシャリスト：給水の効果が下がりました
    • 水の管理人-アクイラ・ドゥルシス：+200% → +100%
    • ドゥクトゥアリウス：+50% → +25%
  • 祭壇：範囲がすべて22マスに揃いました
  • 貯水池：範囲が少し広がり、建てる前の表示と合うようになりました
  • サンダラック苗木場：農園の扱いになり、農園向けの強化が効くようになりました
  • リベルトゥスのパン：輝きで増えるパンの消費量が、プレブスと同じ水準まで下がりました
  • 都市ステータス：属性ペナルティの増え方が、人口ティア2・3の前後でゆるやかになりました。終盤の値は変わりません（街の状況の段階）
  • 護衛の依頼：護衛する船が速くなり、襲ってくる船は遠くに出るようになりました。護衛する船は、依頼を受けた灯台の近くに現れます

公式パッチノートには「ラティウムの粉ひき所の生産時間 30秒→20秒」なども載っていますが、ゲームのデータでは2.0の時点で変わっています（2.0の欄に載せています）。

主な修正（PS5・家庭用ゲーム機） ​

  • 家庭用ゲーム機で、自動セーブの上限が効いていなかったのを修正。手でセーブを消す必要がなくなります
  • PS5のマルチプレイで、進行中のセッションに加わるとセーブのプロファイルが二重にできることがあったのを修正
  • PS5で、総督のヴィラでスペシャリストを割り当てるときに、画面のキーボードが勝手に開くことがあったのを修正
  • コントローラーで、マップの端にいる船を選び直せるようになりました
  • インストールサイズが小さくなりました。そのぶん、この更新のダウンロードは大きくなります

主な修正（PC） ​

  • 画質の自動設定で、「低」のときにフレーム生成が有効になってしまうのを修正
  • RTX 30シリーズでは、自動設定でFSR 3のフレーム生成が既定になります
  • 推奨スペックのPCで、大きく発展した都市の動作が軽くなりました
  • ウィンドウモードの大きさが、次に起動したときも保たれます
  • MODが合わないときの説明に、違っているMODの名前が出ます。ポーズメニューで、MODを使っているゲームかどうかが分かります

主な修正（全機種） ​

  • 「期限切れのメモ」の通知を押すと落ちる不具合、特定のセーブを読み込んだ直後に落ちる不具合を修正
  • 交易ルートの船が、同じ島に戻り続けることがあったのを修正
  • ブドウ・ハチの巣・ワインが、交易と統計の画面に出ていなかったのを修正
  • 騎兵が攻撃の相手を行ったり来たり変えていたのを修正
  • スペシャリストを外す順番で、名声が大きく増減していたのを修正
  • 皇帝の商人（英語名 Emperor's traders）との評判が低くても、失った旗艦の代わりを買えるようになりました
  • マルチプレイの同期ずれ（新しい協力キャンペーン、プレイヤーが置いたメモ、MODの違いが原因のもの）を修正

公式パッチノート：Anno 117: Pax Romana - Patch 3.0（Anno Union）

2.1（2026年9月17日） ​

バランス調整 ​

ヒロイックのスペシャリストのうち、強すぎた3人が調整されました。

  • ラエウィヌス、ウルカヌスのつるはし：効果の対象が、採石場・金選鉱・粘土穴だけになりました（砂精製所を使った稼ぎができなくなります）
  • キルョカンシ、洞穴のごとき飾り箱を持つ男：ライバルとのパッシブ貿易だけが対象になりました。プレイヤー同士の交易は数えません
  • ティランナ、生粋の多色主義者：染料ではなく顔料に効くようになりました

ほかの変更です。

  • 交易の強化は、NPCとプレイヤーの間の数量限定の取引にだけ効くようになりました
  • サンダラック苗木場が農園の分類になりました
  • 期間限定チャレンジの警告が読みやすくなりました
  • 外観変更用のDLC「Echoes of Kassandra Pack」に対応しました

主な修正 ​

  • PS5：前からのセーブを読み込むと落ちることがあったのを修正
  • 競馬場（DLC02）の不具合をいくつか修正。レース中に行進の部隊が出る、計画の研究が解放されない、などです
  • カエシリアを助けたときの外交の悪化が、いつまでも消えなかったのを修正
  • 分かれた水道橋をつないだときの誤った通知、「持ち物がいっぱい」の誤った警告を修正
  • マルチプレイで、もう一度招待すると読み込み画面が終わらないことがあったのを修正

公式パッチノート：Anno 117: Pax Romana - Patch 2.1（Anno Union）

2.0（2026年8月20日） ​

DLC02と同じ日に配信された、DLC不要の大型アップデートです。

新機能 ​

  • 賓客：名声と輝きに応じて各地から賓客が訪れ、新しいスペシャリストなどをもたらします。確率はDLC02ガイドの「来訪する専門家の確率」にまとめています
  • ヒロイックのスペシャリスト：新しいレア度。とても珍しく、名声のコストが高いぶん効果が強力です。同じ人は重ねて現れず、全員集めると出なくなります。効果は、名声が十分な都市でしか働きません
    • （例）「パルディウス」— チーズによる人口+2・健康+1、羊牧場のチーズ産出+1t/12サイクル、羊牧場の必要労働力が75%増える（この効果は未確認です）
  • 住民から、くり返し受けられるクエストが出るようになりました
  • フォトモード：自由に動くカメラ、時間帯の選択、レンズ効果
  • メモ機能：ワールドにメモを置けます。時間がきたら知らせるタイマーも付けられます
  • 置き換え：選んだ建物の下にあるものをまとめて取り壊して建てられます
  • 栄誉の殿堂のページを追加
  • 期間限定チャレンジが、全機種でUbisoft Connectから遊べるようになりました
  • 割り当てのないショートカット（州のマップやクエストログを開くなど）を、自分で設定できます
  • PC版：メインメニューに戻らずにゲームを終えられます。Steamのトレーディングカードに対応しました

遊びやすさ ​

  • 円形闘技場・競馬場のイベントを自動でくり返せます
  • 交易ルート：商品の絞り込みが残るようになり、ルートの複製もできます。PC版ではCtrl+クリックで船に移れます
  • 道路の種類を、道路の建設パネルから切り替えられます
  • 畑や森を、ブラシのように塗って置けます

バランス調整 ​

  • パン：消費量がおよそ50%増えました。そのかわり、満たしたときの人口ボーナスが+2から+3に増えました
  • ラティウムの粉ひき所：生産時間が30秒から20秒になりました（ゲームのデータでは、維持費12・労働力4・小麦の貯蔵12・小麦粉の貯蔵9）
  • 円形闘技場の強化を10段階に作り直しました。輝きレベルIVで、リベルトゥスの需要にパンが加わります（気づかないうちにパンの需要が急に増えるので注意）
  • モニュメントの効果が島全体に効くようになりました
  • 大きな事件（火災・疫病など）で被害を受ける建物が、かなり増えました
  • 外交の贈り物の価値が大きく下がりました
  • 祭りの頻度が下がりました
  • ウルカヌスの強化が、金鉱・炭鉱・金選鉱・炭焼き師にも効くようになりました
  • マルスの強化が、炭鉱・炭焼き師にも効くようになりました

主な修正 ​

  • 途中でライバルを追加すると落ちることがあったのを修正
  • アルビオンで大きな事件を解決できないことがあったのを修正
  • 農場と農園に、畑で働く人が出るようになりました
  • マルチプレイで、ほかの人が持っていないDLCをホストが有効にすると固まる・同期がずれる問題を修正
  • PC版：MODの構成が違う人どうしではマルチプレイができないようになりました

公式パッチノート：Anno 117: Pax Romana - Patch 2.0（Anno Union）
