3.0.1.1（2026年11月20日） ​

装飾品の不具合を2つだけ直す、小さな無料のホットフィックスです。全機種で同時に配信されました。追加の修正を含む通常のパッチは、12月上旬の予定です。

主な修正 ​

  • 栄誉の殿堂で解放した一部の装飾品が、見えない不具合を直しました
  • 一部の装飾品が、港のエリアの水の上に置ける不具合を直しました

PC版で描画の不具合が出るときの回避策として、公式は「ドキュメント」の「Anno 117 – Pax Romana」フォルダにある shaders フォルダの中の「precompiled」フォルダを、削除するか名前を変えるよう案内しています。

公式の案内：Anno 117: Pax Romana - Hotfix 3.0.1.1（Steam）

3.0.1（2026年11月18日） ​

3.0の不具合を直す無料のパッチです。PS5で落ちる・重くなる問題の修正が入っています。

変更点 ​

  • アイギュプトの北の端にある3つの島で、港の建物を建てられる海岸が広がりました。ほかの州との交易の中継地に使いやすくなります
  • 穀物庫：効果が重ならなくなりました。範囲内でいちばんレベルの高い穀物庫の効果だけが働きます（DLC03ガイドの穀物庫）
  • ヘロン地方長官が、筆記板を売って高く買い戻す取引をやめ、代わりに書記道具一式を求めるようになりました
  • タンティエマニ、アペデマクの黄金の建築家：アイギュプトでの効果の対象が、公共施設のすべてから驚異だけになり、弱くなりました
  • 研究「節水施策」（3.0までの名前は「地下のピトス」）が、ラティウムとアルビオンの採石場にも効いていたのを修正。本来は水で強化する鉱山向けの研究です。名前と説明文も変わりました
  • アイギュプトの研究ツリーの最初の関門の説明に、知識50のほかに麦打ち人10人が必要なことが書かれました
  • ライバルが上位の商品を交易に出さず、経済の伸びがひどく遅くなっていた（領土の広げ方や軍備にも響いていた）のを修正
  • 外交：タラゴンが、アイギュプトのビールの生産と消費にも反応するようになりました

効かなかった専門家・アイテムの修正 ​

  • ミウト、水鳥の脅威：ヴィラに付けても効かなかったのを修正
  • 近視の石工：小像の生産チェーンで、大理石の採石場でなく大理石工房に効いていたのを修正
  • ガイウス・ロマーヌス・ガイソス、熱烈な帝国主義者：野営地の部隊に効果が無かったのを修正。回復が速くなります
  • コンセンティア・ストラータ、上等な衣服を渇望する者と収穫の声を聴く者フーイ（アイギュプトのヒロイック）が同じ効果だったのを、別々の効果にしました（強化後の効果は、3.0.1でも同じままです）
  • 黄金の醸造酒-ナンナやラベンダー農家などが、効く建物を亜麻農場と表示していたのを修正
  • イアックス、神秘のテュルソス使い：アイギュプトのラベンダー農場に効かなかったのを修正
  • アイギュプトの青スイレン茶の専門家が、対象の建物の誤りで効かなかったのを修正。セシェン、花摘みの青スイレン茶の生産性の強化も働くようになりました
  • タンティエマニ：アイギュプトとアルビオンの神殿に効かなかったのを修正
  • イシドラ、カラシリスの仕立屋：裁縫工房の生産の強化が働かなかったのを修正
  • デキムス、解任されたデルタの暴君：住居の収入と名声の効果が働かなかったのを修正。割合で増える効果になりました
  • アイギュプトのヒロイックアイテムの確率の強化で、同じ組をもう1組手に入れられてしまうのを修正
  • 州の間を移動中の船に付けた・積んだアイテムが、アイテムの数に入っていなかったのを修正

公式パッチノートには載っていませんが、次の変更もあります。

  • 小スコルピオ・アフリカヌス：効果が「範囲効果: 収入 +2・名声 +1」から「地域における募集スピード +75%」に変わりました
  • ハヌス・レクター、視点の提唱者：3.0までの名前は「ハナ・レクター」です（ゲームのデータの名前で、実機の表記は未確認です）

クエストの修正 ​

  • 護衛の依頼「価値ある戦利品」などで、海賊船が際限なく出続けたのを修正。出る数が限られ、プレイヤーと護衛する船の両方を襲います
  • アイギュプトの商人と海賊のクエストの間隔が、2.5時間のはずが2.5分になっていたのを修正（報酬をくり返し稼げていました）
  • 皇帝の兵の依頼で、アイギュプトで集めた部隊が数えられなかったのを修正。ケルトの世界の軍団兵も、軍団兵の依頼に数えられます
  • 「パンドラのアンフォラ」で、指輪を手元に残すを選んでもルキウスの印章指輪がもらえなかったのを修正
  • 「通訳失敗」の3つ目の目標が、小麦を貯めるのでなく小麦農場を建てる内容になりました
  • 「追放者」で、結末の1つで木材の報酬が届かなかったのを修正
  • アイギュプトのクエストや、アイギュプトで条件を満たした実績が進まない・解除されない不具合をいくつか修正

主な修正（PS5・家庭用ゲーム機） ​

  • PS5で大きな街を映すと、1桁のフレームレートまで落ちることがあったのを修正
  • 家庭用ゲーム機（特にPS5）で、メモリが足りなくなって落ちることがあったのを修正
  • 歩く人の数の上限が効かず、大きな島やセーブでメモリを使いすぎて落ちることがあったのを修正
  • 1フレームごとの処理を減らし、特に大きなセーブで動きが軽くなりました
  • 起動したあと、ときどきカクつくことがあったのを修正
  • コントローラーの操作の修正：研究の画面から信仰の画面に戻ると選択が外れる、交易ルートの編集で地域のタブをLB・RBで選べない、クエストブックの説明を右スティックでスクロールできない、など

主な修正（PC） ​

  • Intel Arc のグラフィックカードを使ったPCで、メインメニューやセーブの読み込みで落ちることがあったのを修正
  • PCにつないだPlayStationのコントローラーで、R3ボタンが効かなかったのを修正

遊びやすさ ​

  • 統計メニューで、島・地域・「すべて」のチェックを直接外せるようになりました
  • アイギュプトの貯水槽を置くとき、水路と同じように灌漑の範囲が出ます
  • 神殿を置くとき、道路での範囲が出るようになりました
  • ピラミッドがミニマップに表示されます
  • アイギュプトで、氾濫期と乾季の始まりに、新しい音で知らせが出ます

分かっている不具合（公式の案内） ​

  • 栄誉の殿堂の地面のプレート、壁、オアシスの茂みがゲーム内に出ません。近いうちに直るそうです
  • 港に一部の装飾を置けるようになっていますが、作りかけの機能のため、置くと崩れて見えます。正式な対応のときに自動では直らないので、港には装飾を置かないよう案内されています
  • 統計メニューを開くと、今の島が選ばれていない（複数の島が選ばれる）ことがあります。12月のパッチで直る予定です
  • PC版で、DLSSのフレーム生成を使うとフレームレートの低下や映像の乱れが出ます。倍率を下げるか、フレーム生成を切ると和らぎます

公式パッチノート：Anno 117: Pax Romana - Patch 3.0.1（Anno Union）

3.0（2026年11月5日） ​

DLCを持っていなくても入る無料アップデートです。

新機能 ​

  • スタンプ機能：住居や生産施設の配置を保存して、あとで再利用できます。名前を付けたり、フォルダに分けたりもできます。PC版では、スタンプのファイルをほかの人と共有できます
  • 統計メニューに「保管」タブと「アイテム・スペシャリスト」タブを追加
    • 保管タブでは、保管中の商品、パッシブ貿易、アクティブ貿易、保管量の増減を確認できます
    • アイテム・スペシャリストタブでは、持っている専門家と、まだ手に入れていない専門家、その入手元を一覧できます
  • クエストログからクエストを隠せるようになりました。隠したクエストは、クエストブックから戻せます
  • 前からのセーブを続ける人向けに、スタンプとメモ機能の短い紹介が出ます
  • 栄誉の殿堂に新カテゴリ「アイギュプト」が加わりました。DLC03を持っていなくても使えます

遊びやすさ ​

  • 祭りを自動で承認するオプションを追加（ゲームオプション）
  • 祭りの総督の決定で、費用の商品を今どれだけ持っているかが表示されます
  • アップグレードの道具で、費用と一緒に建物の名前が出ます
  • 交易ルートを消す前に確認が出ます
  • 交易ルートの詳細画面で戻る操作をすると、画面ごと閉じずにルートの一覧に戻ります
  • アイテムの持ち物を開くと、場面に合った絞り込みが最初から選ばれています
  • カーソルの下にある建物と同じものを建てるショートカットを追加（キーは自分で割り当てます）
  • フォトモードで、カメラを建物の中に入れられます

バランス調整 ​

  • 難易度：新しいセーブでは「ノーマル」が既定になり、商品の消費量が増えます。「簡単」も選べます。消費がさらに75%増える最上位の難易度も追加されました。開始資金も増えます。前からのセーブには影響しません
  • 祭り：始めるのに必要な商品が、商品の価値で決まるようになりました。安い商品は多く、高い商品は少なく必要です。終盤の祭りの費用は、50,000デナリウスから25,000デナリウスに下がります
  • 水道橋の専門家：給水の効果が下がりました
    • 水の管理人-アクイラ・ドゥルシス：+200% → +100%
    • ドゥクトゥアリウス：+50% → +25%
  • 祭壇：範囲がすべて22タイルに揃いました
  • 貯水池：範囲が少し広がり、建てる前の表示と合うようになりました
  • サンダラック苗木場：農園の扱いになり、農園向けの強化が効くようになりました
  • リベルトゥスのパン：輝きで増えるパンの消費量が、プレブスと同じ水準まで下がりました
  • 街の状況：属性ペナルティの増え方が、人口ティア2・3の前後でゆるやかになりました。終盤の値は変わりません（街の状況の段階）
  • 護衛の依頼：護衛する船が速くなり、襲ってくる船は遠くに出るようになりました。護衛する船は、依頼を受けた灯台の近くに現れます

公式パッチノートには「ラティウムの粉ひき所の生産時間 30秒→20秒」なども載っていますが、ゲームのデータでは2.0の時点で変わっています（2.0の欄に載せています）。

主な修正（PS5・家庭用ゲーム機） ​

  • 家庭用ゲーム機で、自動セーブの上限が効いていなかったのを修正。手でセーブを消す必要がなくなります
  • PS5のマルチプレイで、進行中のセッションに加わるとセーブのプロファイルが二重にできることがあったのを修正
  • PS5で、総督のヴィラで専門家を割り当てるときに、画面のキーボードが勝手に開くことがあったのを修正
  • コントローラーで、マップの端にいる船を選び直せるようになりました
  • インストールサイズが小さくなりました。そのぶん、この更新のダウンロードは大きくなります

主な修正（PC） ​

  • 画質の自動設定で、「低」のときにフレーム生成が有効になってしまうのを修正
  • RTX 30シリーズでは、自動設定でFSR 3のフレーム生成が既定になります
  • 推奨スペックのPCで、大きく発展した都市の動作が軽くなりました
  • ウィンドウモードの大きさが、次に起動したときも保たれます
  • MODが合わないときの説明に、違っているMODの名前が出ます。ポーズメニューで、MODを使っているゲームかどうかが分かります

主な修正（全機種） ​

  • 「期限切れのメモ」の通知を押すと落ちる不具合、特定のセーブを読み込んだ直後に落ちる不具合を修正
  • 交易ルートの船が、同じ島に戻り続けることがあったのを修正
  • ブドウ・ハチの巣・ワインが、交易と統計の画面に出ていなかったのを修正
  • 騎兵が攻撃の相手を行ったり来たり変えていたのを修正
  • 専門家を外す順番で、名声が大きく増減していたのを修正
  • 皇帝の商人（英語名 Emperor's traders）との評判が低くても、失った旗艦の代わりを買えるようになりました
  • マルチプレイの同期ずれ（新しい協力キャンペーン、プレイヤーが置いたメモ、MODの違いが原因のもの）を修正

公式パッチノート：Anno 117: Pax Romana - Patch 3.0（Anno Union）

2.1（2026年9月17日） ​

バランス調整 ​

ヒロイックの専門家のうち、強すぎた3人が調整されました。

  • ラエウィヌス、ウルカヌスのつるはし：効果の対象が、採石場・金選鉱・粘土穴だけになりました（砂精製所を使った稼ぎができなくなります）
  • キルョカンシ、洞穴のごとき飾り箱を持つ男：ライバルとのパッシブ貿易だけが対象になりました。プレイヤー同士の交易は数えません
  • ティランナ、生粋の多色主義者：染料ではなく顔料に効くようになりました

ほかの変更です。

  • 交易の強化は、NPCとプレイヤーの間の数量限定の取引にだけ効くようになりました
  • サンダラック苗木場が農園の分類になりました
  • 期間限定チャレンジの警告が読みやすくなりました
  • 外観変更用のDLC「Echoes of Kassandra Pack」に対応しました

主な修正 ​

  • PS5：前からのセーブを読み込むと落ちることがあったのを修正
  • 競馬場（DLC02）の不具合をいくつか修正。レース中に行進の部隊が出る、計画の研究が解放されない、などです
  • カエシリアを助けたときの外交の悪化が、いつまでも消えなかったのを修正
  • 分かれた水道橋をつないだときの誤った通知、「持ち物がいっぱい」の誤った警告を修正
  • マルチプレイで、もう一度招待すると読み込み画面が終わらないことがあったのを修正

公式パッチノート：Anno 117: Pax Romana - Patch 2.1（Anno Union）

2.0（2026年8月20日） ​

DLC02と同じ日に配信された、DLC不要の大型アップデートです。

新機能 ​

  • 賓客：名声と輝きに応じて各地から賓客が訪れ、新しい専門家などをもたらします。確率はDLC02ガイドの「来訪する専門家の確率」にまとめています
  • ヒロイックの専門家：新しいレア度。とても珍しく、名声のコストが高いぶん効果が強力です。同じ人は重ねて現れず、全員集めると出なくなります。効果は、名声が十分な都市でしか働きません
    • （例）「パルディウス」— チーズによる人口+2・健康+1、羊牧場のチーズ産出+1t/12サイクル、羊牧場の必要労働力が75%増える
  • 住民から、くり返し受けられるクエストが出るようになりました
  • フォトモード：自由に動くカメラ、時間帯の選択、レンズ効果
  • メモ機能：ワールドにメモを置けます。時間がきたら知らせるタイマーも付けられます
  • 置き換え：選んだ建物の下にあるものをまとめて取り壊して建てられます
  • 栄誉の殿堂のページを追加
  • 期間限定チャレンジが、全機種でUbisoft Connectから遊べるようになりました
  • 割り当てのないショートカット（州のマップやクエストログを開くなど）を、自分で設定できます
  • PC版：メインメニューに戻らずにゲームを終えられます。Steamのトレーディングカードに対応しました

遊びやすさ ​

  • 円形闘技場・競馬場のイベントを自動でくり返せます
  • 交易ルート：商品の絞り込みが残るようになり、ルートの複製もできます。PC版ではCtrl+クリックで船に移れます
  • 道路の種類を、道路の建設パネルから切り替えられます
  • 畑や森を、ブラシのように塗って置けます

バランス調整 ​

  • パン：消費量がおよそ50%増えました。そのかわり、満たしたときの人口ボーナスが+2から+3に増えました
  • ラティウムの粉ひき所：生産時間が30秒から20秒になりました（ゲームのデータでは、維持費12・労働力4・小麦の貯蔵12・小麦粉の貯蔵9）
